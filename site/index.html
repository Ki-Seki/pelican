How it works

Every session, wherever you started it

  1. Claude Code writes it down. Every session it runs, in the terminal, Claude Desktop or your editor, goes into a transcript in ~/.claude.
  2. Pelican reads it, live. One small process on your computer follows those transcripts, back past every compaction, and continues a session through the official Agent SDK, with your login, settings, CLAUDE.md, skills and MCP servers. Claude Code talks to Anthropic, or your provider, as it always does.
  3. Your phone opens Pelican. Over Tailscale or an SSH tunnel, signed in. Nothing sits in between.

A session another app is working on says which app, and when it waits for you there. Once it is idle, continue it here.

All of Claude Code

What you do at your desk, from your phone

Pelican runs Claude Code itself, so everything you set up for it applies. On top of that, what you would reach for in the terminal:

  • Approve with the diff. Every edit and command waits for you, shown the way you would review it; answer Claude’s questions with a tap, or 1 to 9 on a computer. Or pick a mode, as in Claude Code: Accept edits, Plan, Auto or Bypass.
  • A terminal beside the conversation. Your own shell in the session’s folder, as in Claude Desktop: type straight into it on a computer, or into a line with a row of keys on a phone. It runs on when the page closes, and comes back as it was.
  • Quotes with notes. Select part of a reply, a command’s output, lines of a file or the terminal, and Quote it with a note of your own, as in Claude Desktop. Quotes and line comments wait above the box and go to Claude in Desktop’s own words.
  • Send now, or queue for later. Tell Claude something while it works, and it reads it at its next step; or queue it for after this turn, and take it back until then. Stop is always at hand.
  • Changes, files, Create PR. All of the changes, as /diff counts them, or what each turn changed, with diffs to comment on. Commit changes and Create PR send Claude Desktop’s own requests, and the pull request shows as a card.
  • Every action where you use it. Each thing has one short list of actions: a long press on a phone, a right-click on a computer, or ⌘K, with Claude Desktop’s words and keys.
  • Rewind and fork. Go back to before any message, the code, the conversation or both, with Undo rewind; or fork from any message into a new session, as in Claude Desktop.
  • Side chats. Ask on the side while the session works, as in Claude Desktop, with the passage you are asking about; each is kept with its session, on your phone and your computer alike.
  • ! commands. Run a command in the session’s folder and watch its output as it comes, with Stop. Claude answers when it ends, as in the terminal.
  • Visuals, pages and files. Charts Claude draws, pages it writes and files it sends you, in place, as in Claude Desktop; pages as still pictures until you tap Run.
  • Every model, every command. Opus to Haiku, effort up to max, fast mode, as Claude Code’s own settings start them; / commands and skills, @ files and subagents, photos and files.
  • Notifications. When Claude finishes or needs you, and when a session waits for you in another app. Add Pelican to your Home Screen and it opens like an app.
  • Usage, from every app. Tokens, sessions and streaks by project, model and app, next to your plan’s limits.
  • Updates from Settings. Settings says when a newer Pelican is out, with what changed, and installs it where npm installed Pelican, waiting until nothing runs if you like.
Security

Only you get in

Whoever can use Pelican can run commands as you, so it keeps everyone else out.

Only this computer, unless you say otherwise
It listens on 127.0.0.1, and every browser signs in, there too: with the link Pelican prints, a QR code that works once, or a password.
Guarded against other websites
Host and origin checks stop DNS rebinding and cross-site requests, and no other site may frame it.
What Claude writes stays on the screen
Pages and visuals render in a sandbox that cannot reach Pelican, as still pictures until you tap Run.
Folders run nothing of their own
The hooks, MCP servers, git programs and settings a folder brings wait until you trust it.

Questions

Before you install it

Does it work with my Claude plan?

Pelican runs Anthropic’s own Claude Code, unmodified, on your computer, signed in the way you signed in to claude; it never sees your credentials, and it is for your own use. Signed in with a plan, what you send from Pelican draws from that plan’s limits. The details

Why not Remote Control?

Use it if you are on a Claude plan and want to answer, from your phone, the prompt waiting in your terminal: Pelican cannot. Pelican shows every session without turning anything on, keeps nothing on anyone’s servers, and works with any login, API keys and cloud providers included.

Why not SSH and tmux?

That works, and needs nothing new on the computer. Pelican is for what a terminal on a phone does badly: long transcripts, diffs, approvals in one tap, notifications, charts and pages, and history across compactions.

What if my computer sleeps?

A computer that is asleep runs nothing, and Pelican cannot wake it. While Claude works, Pelican keeps it from going to sleep on its own; keep it awake yourself to reach Pelican at any time.

Does it cost anything, or phone home?

No. Pelican is free and MIT licensed, with no account and no telemetry. It talks to your browser and, for notifications, to the browser’s push service, with the content encrypted.

Why is the install about 150 MB?

The Agent SDK, which Pelican runs Claude Code through, brings its own copy of Claude Code, for your computer alone: about 150 MB to download, about 400 MB on disk. Pelican itself is about 2 MB. The live demo needs no install at all.

Get started

One command, then your phone

  1. Install it

    On the computer where you use Claude Code, with Node 22.12 or newer. pelican prints the link that signs this browser in.

    npm install -g pelican-cc
pelican

  2. Open it on your phone

    With Tailscale on the computer and the phone. Scan the QR code, and Pelican opens there, signed in.

    tailscale serve --bg 7860
pelican phone

  3. Keep it running

    It starts when you log in, and again if it stops.

    pelican service install

About 150 MB to download, about 400 MB on disk, most of it the copy of Claude Code the Agent SDK brings. Other ways in, or try the live demo first.
