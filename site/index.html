How it works

One small server, nothing in between

  1. Your phone opens Pelican over Tailscale or an SSH tunnel, signed in. Nothing sits in between.
  2. Pelican runs Claude Code through the official Agent SDK, with your login, settings, CLAUDE.md, skills and MCP servers.
  3. It reads every transcript Claude Code keeps in ~/.claude, live, back past every compaction, wherever the session started.

Security

Only you get in

Whoever can use Pelican can run commands as you, so it keeps everyone else out.

Only this computer, unless you say otherwise

It listens on 127.0.0.1, and every browser signs in, there too: with the link Pelican prints, a QR code that works once, or a password.

Guarded against other websites

Host and origin checks stop DNS rebinding and cross-site requests, and no other site may frame it.

What Claude writes stays on the screen

Pages and visuals render in a sandbox that cannot reach Pelican, as still pictures until you tap Run.

Folders run nothing of their own

The hooks, MCP servers, git programs and settings a folder brings wait until you trust it.

Questions

Before you install it

Does it work with my Claude plan?

Pelican runs Anthropic’s own Claude Code, unmodified, on your computer, signed in the way you signed in to claude; it never sees your credentials, and it is for your own use. Signed in with a plan, what you send from Pelican draws from that plan’s limits. The details

Why not Remote Control?

Use it if you are on a Claude plan and want to answer, from your phone, the prompt waiting in your terminal: Pelican cannot. Pelican shows every session without turning anything on, keeps nothing on anyone’s servers, and works with any login, API keys and cloud providers included.

Why not SSH and tmux?

That works, and needs nothing new on the computer. Pelican is for what a terminal on a phone does badly: long transcripts, diffs, approvals in one tap, notifications, charts and pages, and history across compactions.

What if my computer sleeps?

A computer that is asleep runs nothing, and Pelican cannot wake it. While Claude works, Pelican keeps it from going to sleep on its own; keep it awake yourself to reach Pelican at any time.

Does it cost anything, or phone home?

No. Pelican is free and MIT licensed, with no account and no telemetry. It talks to your browser and, for notifications, to the browser’s push service, with the content encrypted.

Why is the install about 150 MB?

The Agent SDK, which Pelican runs Claude Code through, brings its own copy of Claude Code, for your computer alone: about 150 MB to download, about 400 MB on disk. Pelican itself is about 2 MB. The live demo needs no install at all.

Get started

One command, then your phone

  1. Install it

    On the computer where you use Claude Code: macOS, Linux or WSL, with Node 22.12 or newer. pelican prints the link that signs this browser in.

    npm install -g pelican-cc
pelican

  2. Open it on your phone

    With Tailscale on the computer and the phone, signed in to the same account. Scan the QR code, and Pelican opens there, signed in.

    tailscale serve --bg 7860
pelican phone

  3. Keep it running

    It starts when you log in, and again if it stops.

    pelican service install

About 150 MB to download, about 400 MB on disk, most of it the copy of Claude Code the Agent SDK brings. Other ways in, or try the live demo first.
