Claude Code, in your pocket.

Pelican is a phone-first web app for the Claude Code on your computer. Follow every session as it runs, answer Claude, approve its edits and start new work, from wherever you are.

Every session

Wherever you started it

Pelican reads Claude Code’s own transcripts. The sessions you began in the terminal, in Claude Desktop or in your editor are all here, live while they run, with their whole history back past every compaction.

  • Live. A session another app is working on shows up as it works, and you can see which app.
  • Whole history. Scroll up to the first prompt, through each compaction, with what Claude kept.
  • Three ways to read. Just the replies, the replies with steps folded, or every step open.

All of Claude Code

What you do at your desk, from your phone

Pelican drives Claude Code through the official Agent SDK, so your login, settings, CLAUDE.md, skills and MCP servers all apply. On top of that, everything you would reach for in the terminal.

Approve with the diff

Every edit and command waits for you, shown the way you would review it. Or let Claude work: plan, accept edits, auto, bypass.

Steer or queue

Tell Claude something while it works and it reads it at its next step, or line up what comes after this turn.

! commands

Run a command in the session’s folder. The output lands in the conversation, and Claude reads it with your next message.

Changes and files

Each changed file with its diff, and the whole folder to browse, read and mention.

Visuals and pages

Charts and diagrams Claude draws, and the pages it writes, rendered in place, in a sandbox.

Rewind and branch

Put files back the way they were before any prompt, or change an earlier prompt and send it again on a branch.

Every model and mode

Opus to Haiku, effort up to max, fast mode and ultracode; / commands, @ files and subagents, photos and files.

Notifications

A push when Claude finishes or needs you. Add Pelican to your Home Screen and it opens like an app.

Yours

Nothing leaves your computer

Pelican is one small Node process next to Claude Code. There is no cloud service in between, no account to make, and no copy of your sessions anywhere but where Claude Code keeps them.

Reach it from your phone through Tailscale, an SSH tunnel or your own proxy.

Only this computer, unless you say otherwiseIt listens on 127.0.0.1, and every browser signs in, there too.
A link that signs you inA random token, printed at start and kept only on your computer, or a password you set there.
Guarded against other websitesHost and origin checks stop DNS rebinding and cross-site requests.

Get started

One command, then your phone

On the computer where you use Claude Code, with Node 22.12 or newer.

Then set it up for your phone, or read the docs.

# see it first, with made-up sessions
npx pelican-cc --demo

# then for real
npm install -g pelican-cc
pelican                  # http://localhost:7860
