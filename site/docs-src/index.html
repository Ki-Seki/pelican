Quick start

  1. Install and start it on the computer where you use Claude Code: macOS, Linux or WSL, with Node 22.12 or newer.
    npm install -g pelican-cc
pelican
  2. Open it on your phone, with Tailscale on both, signed in to the same account. Scan the QR code.
    tailscale serve --bg 7860
pelican phone
  3. Keep it running: pelican service install starts it at login.
