git clone https://github.com/Ki-Seki/pelican
cd pelican
npm ci
npm run dev

npm run dev runs the server on port 7860 and the web app on port 5173, both reloading on change. npm test && npm run typecheck checks a change, npm run build && npm run demo serves the build with made-up sessions, and node scripts/smoke.mjs opens it in a browser and fails on any error. The pictures come from npm run screenshots and node scripts/icons.mjs, and this site with its live demo from node scripts/site.mjs. More in CONTRIBUTING.md.
