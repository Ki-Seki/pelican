What Pelican does of Claude Code’s features, next to the terminal (CLI) and Claude Desktop as Claude Code’s docs describe them on 5 November 2026. Pelican runs Claude Code itself, so what Claude Code does on its own, such as your settings, CLAUDE.md, hooks, skills, subagents, models and any login, works as it does in the terminal; this table is about what you see and use. A dash means that app’s docs describe no such thing. The table is updated with each release.
