There are good ways to reach Claude Code from a phone. What sets Pelican apart is that it works with every session you already have, from any app, and puts nothing between your phone and your computer. As each project documents it, checked on 5 November 2026:

  • Remote Control (Anthropic) connects the Claude app or claude.ai to a session on your computer: run /remote-control in it, start it with claude --remote-control, or turn on Enable Remote Control for all sessions in /config (Claude Desktop and VS Code have the same switch). It forwards permission prompts and questions to your phone with a push, which Pelican cannot do for a session another app is running. It needs a Claude plan; API keys, Bedrock, Google Cloud’s Agent Platform, Microsoft Foundry and LLM gateways are not supported, and on Team and Enterprise an Owner turns it on. Its traffic goes through Anthropic, which stores the transcript while a session is connected, so organizations with Zero Data Retention or the HIPAA configuration cannot use it. From the app you cannot pick Bypass, and a line starting with ! goes to Claude as a message.
  • Yep Anywhere is a web interface for Claude Code and Codex on the Agent SDK, with push notifications and no accounts. It resumes sessions started in the CLI, VS Code and desktop apps, and besides direct access it offers a free relay, end-to-end encrypted.
  • Happy and HAPI run the sessions you start in them: happy claude or hapi claude instead of claude, or Happy’s desktop app. You continue from their apps (HAPI also has a web app) through a relay, end-to-end encrypted. Both run Codex and other agents too.
  • CloudCLI is a web UI for Claude Code, Cursor CLI and Codex, with a file explorer, git and a shell. It finds every session in ~/.claude; you run it on your network, or use CloudCLI Cloud, a hosted environment.
  • SSH and tmux need nothing new on the computer: run claude inside tmux and reach it from an SSH app. Pelican is for what a terminal on a phone does badly: long transcripts, diffs, approvals in one tap, notifications, charts and pages, and history across compactions.
