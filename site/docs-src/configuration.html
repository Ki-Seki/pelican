pelican token prints the link that signs a browser in (Pelican shows it at start only on a terminal, never in a log), and pelican token --reset makes a new token. pelican password sets a password, which replaces the token until pelican password --off removes it. A new token or password signs every browser out at once, with no restart. pelican login signs Claude Code in. pelican phone is under Use it from your phone, and pelican service under Keep it running. If the port is taken, Pelican says whether it already runs there; pelican token and pelican phone find a running Pelican’s port by themselves.
